# Screenshot visual review

Reviewed on 2026-09-22 by an independent reviewer. The review covered all 55 full-profile products and inspected the stored pixels rather than filenames or page metadata. Each result is recorded in `manifest.json` and bound to the reviewed image SHA-256 digest.

## Replaced and accepted

| Product | Result |
| --- | --- |
| Amp | Direct Mac application with an active thread, thread list and changes pane. |
| Antigravity | Direct full application workspace instead of a promotional overview. |
| Cursor | Direct agent workspace with multiple named tasks and a changes pane. |
| Factory | Direct mission application with orchestrator, worker and validator sessions. |
| JetBrains Air | Direct application window with Agent Sessions, several tasks, an input-required state and chat. |
| Ona | Direct Home view with recent sessions and visible review states. |
| OpenHands | Conversation workspace with an active task and four named conversations, not the Automate screen. |
| Paseo | Direct workspace with chat, changes and work grouped into three states. |
| Podium | Work view with active chat and work items in Done, Running, Standing by and Blocked states. |
| QM | Direct chat workspace with seven named sessions. |
| Super | Direct application workspace without the previous logo overlay. |
| Warp Oz | Direct Runs view. This is the strongest available first-party populated view. |

Jules and GitHub Copilot were also replaced with more direct first-party interface images, but remain marked as fallbacks because the Jules image lacks a populated task list and the Copilot asset crops the right side of the application.

## Accepted without replacement

Conductor, Superset, T3 Code, Orca, CodeLayer, Multica, Solenta, Synara, Maestro, Agent Orchestrator, Rookery, Linzumi, Replicas, Jean, Emdash, Lanes, cmux, xum, Tembo, Proliferate, Verdent, Zenflow, Intent, Superconductor, Zed Delta, Zencoder, Buzz, Devin, Kiro, Augment Code, OpenCode, Cline, Zed, Warp and OpenSpec.

Lanes, Superconductor and Zed have minor framing or population limits, but still show enough direct working interface to pass the acceptance gate.

## Open fallbacks

| Product | Limitation and search result |
| --- | --- |
| Capy | Populated Slack workspace rather than a standalone Capy surface. No downloadable dashboard was found on the homepage or docs. |
| Claude Code | Real first-party task interface with decorative framing and annotations. No cleaner official capture was found. |
| Codex | Real app screenshot from a third-party mirror. The official images reviewed were empty or feature-level composer views. |
| GitHub Copilot | Direct app fragment with sessions and task states, but the official asset crops the application. |
| Jules | Direct repository task input, but no populated task list was found on the homepage, docs or changelog. |
| Omnara | Angled laptop and phone montage. No cleaner downloadable view was found on the product sites or public repository. |
| Omnigent | Named sessions are visible, but the central composer is empty. No stronger repository asset was found. |
| Unpeel | Real UI includes a headline and phone montage. No clean product-only capture was found on the homepage, docs, changelog or repository. |

Fallbacks remain in the library for visual context, but do not count as accepted screenshot coverage. Future research passes must continue looking for direct, populated product views.
